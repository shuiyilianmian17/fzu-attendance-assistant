# 智汇福大晚点名自动签到

Windows 桌面辅助程序，通过雷电或 MuMu 模拟器中的安卓版智汇福大完成晚点名操作。支持设定时间、启动补签、自动进入页面、重新发送定位和确认签到结果。

## 下载安装

**[下载最新一键安装包](https://github.com/shuiyilianmian17/fzu-attendance-assistant/releases/latest/download/FzuAttendanceAssistant-Setup-1.0.12.exe)** · [全部发布版本](https://github.com/shuiyilianmian17/fzu-attendance-assistant/releases)

升级时先从托盘退出旧版助手，再安装新版，原设置会保留。

下载 `FzuAttendanceAssistant-Setup-1.0.12.exe`，双击后点“立即安装”。安装程序会创建桌面快捷方式，并让助手在登录 Windows 后启动。无需管理员权限，不需要另外安装 Python、Node.js 或开发工具。

需要 Windows 10 1903 及以上或 Windows 11，64 位系统与 .NET Framework 4.8。现代 Windows 已包含这一运行环境。

安装包包含助手本身。雷电模拟器、安卓版智汇福大和账号登录需要首次自行配置，不随包分发。

## 首次配置

1. 安装 MuMu 模拟器（也兼容雷电），在模拟器中安装并登录学校官方提供的安卓版智汇福大。
2. 将“晚点名签到”加入智汇福大的“我的服务”。
3. 默认使用旗山校区附近的位置，助手启动 MuMu 后自动发送，无需手动定位；如需修改，可在运行环境中填写并保存。
4. 打开助手的“运行环境”，自动查找 MuMu，或选择其 `nx_main` 目录中的 `mumu-cli.exe`（雷电选择 `ldconsole.exe`），填写对应实例编号，第一个实例通常为 `0`。
5. 点“检查连接”验证页面和定位；在“签到设置”选择 `21:00–23:59` 内的时间，启用自动签到并保存。

新安装默认暂停自动签到，完成上述配置后再开启。v1.0.1 已移除 Windows 版智汇福大的旧模式和相关按钮。平时只运行托盘助手，到了时间才启动或连接模拟器。关闭设置窗口不会退出助手，从托盘菜单可以退出。

## 工作方式

- 支持每天自定时间，以北京时间为准。
- 启动助手或电脑从睡眠恢复时，若已到设定时间、仍在签到时段且当日未成功，会尝试立即补签。
- 后台启动模拟器、查找晚点名入口，随后重新发送雷电已选的位置；定位等待期间会再次发送。
- 只在当日页面允许签到且仍在签到时段时操作按钮。
- 读取页面“已签到”或“签到成功”后，才将当天标记为成功；未确认成功则记录状态并稍后重试。
- 支持显示后台只读画面、手动重新定位和重启安卓应用。
- 可“打开模拟器窗口”进行手动登录或操作；“关闭模拟器”仅关闭所选实例，助手恢复自动签到；已过设定时间且仍在签到时段时立即补签。手动窗口打开期间暂缓自动点击。
- 自动识别并关闭已适配的雷电广告弹窗，确认广告消失后继续打开智汇福大；未识别到关闭按钮时提示具体原因。
- 动态解析 Android 启动入口，区分系统权限提示、登录页、安卓桌面和空白画面。
- 入口识别失败时可点“导出诊断”，获取不含账号、坐标、令牌或截图的诊断文件。

电脑需要开机并联网；睡眠期间不会执行。登录过期需要本人重新登录。模拟器中保存的固定位置不会随本人移动而更新，应按实际位置配置，并遵守学校的签到要求。

已在雷电 14 与智汇福大安卓版 1.17.4 上验证页面导航、后台重新定位和实际签到；其他版本的页面结构或兼容性可能不同。

## 设置与隐私

安装版的设置和日志保存在 `%LOCALAPPDATA%\FzuAttendanceAssistant`。升级不会覆盖个人设置，卸载后保留这些数据。便携版将设置和日志保存在程序所在文件夹。

仓库和发布包不包含账号密码、会话令牌、定位坐标、运行日志或个人签到截图。账号登录由智汇福大和模拟器管理。软件不是学校官方客户端。

## 从源码构建

在 Windows x64 的 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成文件位于 `dist\portable`。制作安装包需要 [Inno Setup](https://jrsoftware.org/isdl.php)：

```powershell
powershell -ExecutionPolicy Bypass -File .\release.ps1 -IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

发布脚本先运行时间规则、安卓页面状态与界面交互检查，再生成安装版、便携版和 SHA-256 校验文件。发布内容使用明确的文件清单，不从运行目录整体打包。

发布包尚未进行商业代码签名，Windows 可能显示发布者未验证的提示。

## MuMu 配置

选择 MuMu 安装目录 `nx_main` 中的 `mumu-cli.exe`（也兼容 `MuMuManager.exe`），实例编号与多开器一致。在 MuMu 中安装并登录智汇福大，加入晚点名入口。助手已内置旗山校区附近的位置，无需在 MuMu 中手动调整；如需其他位置，可在运行环境中修改并保存。助手独立保存此位置，每次启动和进入晚点名后重新发送，等待期间重复刷新。已于 2026-10-29 在 MuMu Android 15 上完成真实签到，确认页面显示成功，并验证模拟器随后自动退出。

## 自动查找与软件更新

自动查找优先识别 MuMu，检查运行进程、当前用户和系统安装记录、应用路径、快捷方式，以及各固定磁盘的常见安装目录；也兼容雷电。找到后保存运行环境即可。无法识别的自定义安装仍可手动选择控制程序。

在签到概览或托盘菜单点击“检查更新”。确认新版后自动从本仓库下载安装包，验证 SHA-256，再覆盖更新并在托盘重新运行。保留现有时间、模拟器路径和自启选择；便携版更新保留原数据目录。网络或校验失败不会启动安装。GitHub 公共接口限流时使用官方发布页和校验文件回退。旧版本需要手动安装 v1.0.5 一次，以后可在软件内更新。

## 签到后自动关闭

自动签到或“立即尝试签到”确认当日页面显示“已签到／签到成功”后，助手会自动关闭所选模拟器实例，并记录关闭完成。关闭失败时保留成功结果和待关闭状态，每分钟重试关闭，不重复签到；助手重启后继续恢复待关闭操作。手动操作模式不会被自动关闭，只读检查与重新定位不会触发这一流程。

安装包内置发布者提供的旗山校区附近默认位置；个人修改后的设置仍保存在本机。位置改变时，请重新核对并保存；不会跟随人移动。保存签到设置、启动或恢复电脑时，若已过设定时间且仍在 21:00–23:59 内，会立即检查；正在手动操作模拟器时暂缓，关闭后恢复。失败后间隔 5 分钟重试，当天确认成功后不重复提交。

从 v1.0.12 起，新安装以及未保存位置的旧配置会使用内置旗山校区默认位置。启动 MuMu、打开模拟器窗口和进入晚点名后自动发送；用户已保存的自定义位置保留。可点击“恢复旗山校区默认位置”，再保存运行环境。内置固定位置不代表设备的实时位置。

诊断会显示实际模拟器类型、控制程序及 MuMu 实例状态；隐藏页支持滚轮和上下拖动。

用户操作优先：检查更新、检查连接、重启应用、重新定位及模拟器开关会中断当前后台流程。检查更新立即联网，不要求先等待签到结束；已经确认的签到记录保留。

每次签到在保存的位置中心5米内生成本次临时位置，同一次流程保持一致。先等待模拟器就绪，重新发送定位并确认控制命令成功，再启动智汇福大；进入晚点名后继续刷新。临时位置不覆盖保存的中心点。
